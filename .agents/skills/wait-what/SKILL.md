# Wait what

Stop. The last message assumed context the owner does not have. Re-pitch it before doing anything else.

## Procedure

1. **Name the missing context.** Identify what the last message assumed: a term, a prior decision, a module, a step, or a result the owner has not seen. Skipping this repeats the same blind spot.
2. **Check the glossary.** Read `GLOSSARY.md` at the repo root (or follow `GLOSSARY-MAP.md` to the active context). Use the project's exact terms so your explanation matches the owner's mental model.
3. **Re-pitch in plain English.** Start from the missing context. Use short sentences, one idea per sentence, active voice. Define any term outside the glossary. Add no new findings, options, or next steps; the owner asked for the same message in words they can follow.
4. **Stop and wait.** End immediately after the re-pitch. Do not continue the task, ask a new question, or propose a plan.

When the owner challenges a finding, a recommendation, or a fact, load `pushback` before you reply.
